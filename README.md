# Iris-Flower-Classification-App
This is a Machine learning model. which classify iris flower species. User Interface built by streamlit. 
1. user friendly
2. Accurately classify
3. Show prediction, probability and also image of flower
4. Model used Logistic Regression
5. accuracy of model 99%

# Dataset 
"Iris classification dataset" which is already built in on sickit learn library. 

# Model details
All information about training and testing of model is available on "classification_iris.ipynb".
